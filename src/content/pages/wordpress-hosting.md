## Každý tarif obsahuje

Instalaci WordPressu jedním kliknutím, automatické aktualizace jádra, SSL zdarma (Let's Encrypt), denní zálohy (14 dní), PHP 8.3 + MySQL 8 a NVMe SSD úložiště.

## Potřebujete plnou správu?

Managed hosting přidává aktualizace pluginů, bezpečnostní monitoring a prioritní podporu. Hodí se pro e-shopy a weby, které si nemůžou dovolit výpadek.

## Kam dál

- **Standardní webhosting** — NVMe hosting pro vlastní PHP aplikace. Od 49 Kč měsíčně.
- **Managed hosting** — plná správa: aktualizace, zálohy, monitoring i podpora.
- **WordPress návody** — instalace, migrace, cache pluginy a obnova zálohy.

Ceny jsou uvedeny bez DPH.
